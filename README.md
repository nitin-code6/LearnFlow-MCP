# LearnFlow-MCP

A Moodle-like Learning Management System built from scratch as a learning project.

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL + Prisma (upcoming)
- Integration: Python FastMCP + Claude (upcoming)

## Getting Started

### Prerequisites
- Node.js installed

### Running Locally

1. **Backend**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
